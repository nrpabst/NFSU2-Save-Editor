# Changelog

## 1.0.0

First release.

- Set your cash.
- Unlock 100% career progress and keep your own cars.
- Add, swap or remove career garage cars, stock or as one of 12 fully modded builds.
- Max out performance, and change body kits, widebodies, hoods, lights and more.
- Edit the Quick Race garage (My Cars).
- Writes valid checksums, so nfsu2.xyz doesn't flag the save as edited.
- Windows app that updates itself, plus the same editor as an HTML file and online.
